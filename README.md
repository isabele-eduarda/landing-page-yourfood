Uma landing page moderna, responsiva e interativa desenvolvida para um site do ramo alimentício (restaurante). O projeto foca em uma experiência de usuário fluida, com animações suaves de rolagem e ícones estilizados.

## 🚀 Tecnologias e Bibliotecas Utilizadas

Este projeto foi construído utilizando as seguintes tecnologias e ferramentas:

* **HTML5:** Estruturação semântica da página.
* **CSS3:** Estilização, variáveis CSS, layout responsivo.
* **JavaScript:** Lógica de interatividade.
* **[Iconify](https://iconify.design/):** Biblioteca de ícones versátil utilizada para ilustrar elementos da interface.
* **[ScrollReveal.js](https://scrollrevealjs.org/):** Biblioteca JavaScript para animações de revelação conforme o usuário rola a página.

---

## ✨ Funcionalidades

* 📱 **Design Responsivo:** Adaptado para diferentes tamanhos de tela (desktop, tablets e celulares).
* ✨ **Animações de Rolagem:** Elementos aparecem suavemente na tela.
* 🍔 **Seções Estruturadas:**
  * **Início (Home):** Chamada para ação (CTA) chamativa.
  * **Cardápio** Exibição dos pratos principais.
  * **Depoimentos** Feedbacks do estabelecimento.
  * **Rodapé:** Informações de redes sociais.

## 💻 Como Rodar o Projeto

Para executar o projeto localmente na sua máquina, siga os passos abaixo:

1. Clone este repositório
```bash git clone [https://github.com/isabele-eduarda/landing-page-yourfood](https://github.com/isabele-eduarda/landing-page-yourfood.git)
```
2. Abra a pasta do projeto no seu editor de código favorito (como o VS Code).
3. Abra o arquivo index.html:
  * Você pode dar dois cliques no arquivo para abri-lo no navegador, ou
  * Utilizar a extensão Live Server no VS Code para uma melhor experiência de desenvolvimento com atualização automática.
